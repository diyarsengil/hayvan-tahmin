BUZUL KAŞİFİ — YÜKLEME PAKETİ

YERELDE AÇMA
1. ZIP dosyasını önce tamamen dışarı çıkarın.
2. Çıkan klasörde Baslat.bat dosyasına çift tıklayın.
3. Site tarayıcıda http://127.0.0.1:8000 adresinde açılır.
4. Kapatmak için açılan sunucu penceresini kapatın.

İNTERNETE YÜKLEME
Klasörün içindeki web dosyalarını bir statik web sitesi barındırma hizmetine (ör. GitHub Pages, Netlify veya Vercel) yükleyin. index.html kök dizinde bulunmalıdır. Baslat.bat dosyasını internete yüklemeniz gerekmez.

İÇERİK
- index.html: Ana sayfa
- styles.css, gallery.css, habitat.css, habitat-photos.css: Tasarım dosyaları
- script.js: Model bağlantısı, görsel yükleme, tahmin ve tür galerileri
- Baslat.bat: Windows'ta yerel önizleme sunucusunu başlatır

ÖNEMLİ
- ZIP'in içinden index.html'i çalıştırmayın; önce ZIP'i çıkarın.
- Model ve örnek fotoğraflar için internet bağlantısı gerekir.
- Yerel başlatıcı Python gerektirir. Python yüklü değilse dosyaları bir statik web barındırma hizmetine yükleyin.
- Model adresi script.js içinde ayarlanmıştır.
